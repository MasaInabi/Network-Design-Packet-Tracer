# Network Design - Cisco Packet Tracer

A computer network design and configuration project developed using Cisco Packet Tracer.

## Project Overview

This project demonstrates the design and configuration of a multi-network topology connecting multiple networks through routers and switches.

The network includes different end devices and servers, with routing configured to enable communication between the networks.

## Features

- Multiple interconnected networks
- Routers and switches configuration
- IPv4 addressing
- Subnetting
- Routing between networks
- Default gateway configuration
- Server configuration
- End-device connectivity
- Network connectivity testing

## Network Components

- Routers
- Switches
- PCs and Laptops
- Servers
- Wireless Access Point
- Multiple LAN networks

## Technologies & Concepts

- Cisco Packet Tracer
- IPv4
- Subnetting
- Routing
- LAN/WAN Networking
- Network Topology Design

The `.pkt` file included in this repository can be opened using **Cisco Packet Tracer** to explore, run, and test the complete network topology.
